# 🏰 Cyber Citadel — Cyberpunk Tower Defense

> Neon tactical tower defense built in pure HTML5 Canvas & Web Audio API. Zero dependencies, offline-first, mobile & desktop optimized.

Part of the **[Mini Arcade Hub](https://lwn2210.github.io/mini-arcade/)**.

## 🎮 Play Live
- **Direct Play:** [https://lwn2210.github.io/mini-arcade/citadel/](https://lwn2210.github.io/mini-arcade/citadel/)

## ⚡ Game Features
- **4 Specialized Turrets:**
  - 🔵 **Laser Pulse:** High rate of fire, reliable single-target DPS.
  - 🟣 **Plasma Mortar:** Long range artillery with massive AoE splash damage.
  - ❄️ **Cryo Emitter:** AoE cryogenic field that freezes and slows enemy units.
  - ⚡ **Tesla Coil:** High-voltage chain lightning chaining across multiple foes.
- **3 Upgrade Tiers + Sell Refund:** Upgrade range, damage, and attack speed on any active turret, or sell back for tactical redeployment.
- **20 Escalating Waves:** Mecha Scouts, Assault Walkers, Shielded Heavies, and Titan Mecha Bosses.
- **Procedural Web Audio Synthesizer:** Real-time laser chirps, plasma booms, frost whooshes, electrical arcs, and alarm sirens — zero audio asset lag.
- **Virality & Sharing:** 1-tap WhatsApp and social media score bragging (`Pamer Rekor`).
- **Responsive Controls:** Intuitive touch targeting on mobile smartphones and mouse navigation on desktop.

## 🛠️ Tech Stack
- HTML5 Canvas 2D
- Web Audio API (real-time synthesizer)
- LocalStorage High Score System
- Zero external runtime libraries
